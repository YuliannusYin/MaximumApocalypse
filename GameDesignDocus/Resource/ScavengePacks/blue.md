# 蓝色拾荒牌堆

## 蓝色拾荒牌

### 弹药（少量）

- 类别：战备
- 颜色：蓝色
- 类型：行动
- 数值：2

**技能：弹药（少量）**

- 技能描述：行动：向一张武器卡填装2发弹药。
- 技能类型：行动
- 可用阶段：行动阶段
- 可用条件：处于行动阶段，且玩家剩余行动次数大于 0
- 目标选择：1 个
- 目标筛选：玩家装备区内、填充物类型为弹药、且当前填充数未达上限的装备
- 效果：向目标装备添加 2 发弹药

### 防弹背心

- 类别：战备
- 颜色：蓝色
- 类型：装备
- 装备栏：1 格

**技能：防弹背心**

- 技能描述：被动：受到的伤害减少2点，使用三次后销毁。
- 技能类型：装备
- 触发时机：受到伤害时
- 强制发动：是
- 效果：本次受到的伤害值减 2；累计使用 3 次后销毁此装备

### 对讲机

- 类别：战备
- 颜色：蓝色
- 类型：装备
- 装备栏：1 格

**技能：对讲机**

- 技能描述：行动：选择另一名玩家，该玩家立即执行一个行动。
- 技能类型：装备
- 可用阶段：行动阶段
- 可用条件：处于行动阶段，且玩家剩余行动次数大于 0
- 目标选择：1 个
- 目标筛选：另一名人类玩家
- 目标范围：无距离限制
- 效果：消耗 1 点行动次数，使目标玩家立即执行一个行动

### 手枪

- 类别：战备
- 颜色：蓝色
- 类型：装备
- 装备栏：1 格
- 填充物：弹药 上限 4 初始 4
- 射程：中距离

**技能：手枪**

- 技能描述：行动：对一个目标造成2点伤害。
- 技能类型：装备
- 可用阶段：行动阶段
- 可用条件：处于行动阶段，且玩家剩余行动次数大于 0，且手枪弹药数大于 0
- 目标选择：1 个
- 目标筛选：任意目标
- 目标范围：中距离
- 效果：消耗 1 点行动次数与 1 枚弹药，对目标造成 2 点伤害，伤害来源为该玩家

### 背包

- 类别：战备
- 颜色：蓝色
- 类型：装备
- 装备栏：0 格

**技能：背包**

- 技能描述：被动：玩家增加1格装备栏。
- 技能类型：装备
- 触发时机：卡牌进入装备区时、卡牌离开装备区时
- 强制发动：是
- 可用条件：触发卡牌为「背包」
- 效果：进入装备区时玩家装备栏 +1 格；离开装备区时 -1 格

### 手电筒

- 类别：战备
- 颜色：蓝色
- 类型：装备
- 装备栏：1 格

**技能：手电筒**

- 技能描述：被动：当你执行拾荒行动时，改为展示牌堆顶两张牌，然后你选择保留其中一张，将另一张置于牌堆底。
- 技能类型：装备
- 触发时机：抓取拾荒牌前
- 强制发动：是
- 效果：替代原有拾荒逻辑：展示拾荒牌堆顶 2 张牌，玩家保留其中 1 张（触发抓取效果），将另一张置于牌堆底

### 双筒望远镜

- 类别：战备
- 颜色：蓝色
- 类型：装备
- 装备栏：1 格
- 射程：长距离

**技能：双筒望远镜**

- 技能描述：行动：展示一张地图块，且不触发它的展示效果。
- 技能类型：装备
- 可用阶段：行动阶段
- 可用条件：处于行动阶段，且玩家剩余行动次数大于 0
- 目标选择：1 个
- 目标筛选：未展示的地图块
- 目标范围：长距离
- 效果：消耗 1 点行动次数，展示一个未展示的地图块，不触发其展示效果
