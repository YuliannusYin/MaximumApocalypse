# 机械师

## 角色详情

- 英文名：mechanic
- 生命值上限：26
- 初始生命值：26
- 潜行值：8
- 饥饿状态潜行值：7
- 装备栏容量：4
- 手牌上限：10

## 固有技能

### 维修

- 技能描述：行动：从场上所有弃牌堆中选择一张装备牌返回手牌。
- 可用阶段：行动阶段
- 可用条件：处于行动阶段，且玩家剩余行动次数大于 0，且场上所有弃牌堆中至少有 1 张装备牌
- 效果：消耗 1 点行动次数，从场上所有弃牌堆（含所有玩家弃牌堆与拾荒弃牌堆）中选择一张装备牌，获得此牌

## 角色游戏牌堆

### 扳手 ×3

- 类型：装备
- 装备栏：1 格
- 射程：短距离
- 武器：是

**技能：扳手**

- 技能描述：行动：对一个目标造成2点伤害。
- 技能类型：装备
- 可用阶段：行动阶段
- 可用条件：处于行动阶段，且玩家剩余行动次数大于 0
- 目标选择：1 个
- 目标筛选：任意目标
- 目标范围：短距离
- 效果：消耗 1 点行动次数，对目标造成 2 点伤害，伤害来源为该玩家

### 钉子炸弹 ×2

- 类型：行动

**技能：钉子炸弹**

- 技能描述：行动：对射程内的最多3个怪物各造成5点伤害
- 技能类型：行动
- 可用阶段：行动阶段
- 可用条件：处于行动阶段，且玩家剩余行动次数大于 0
- 目标选择：1~3 个
- 目标筛选：怪物类型的目标
- 目标范围：中距离
- 效果：对每个目标造成 5 点伤害，伤害来源为该玩家

### 感应地雷 ×3

- 类型：装备
- 装备栏：1 格
- 武器：是

**技能：感应地雷**

- 技能描述：被动：当你抓取一张怪物卡后，弃掉此装备并对该怪物造成7点伤害。
- 技能类型：装备
- 触发时机：抓取怪物卡后
- 强制发动：是
- 效果：弃置此装备，对所抓取的怪物卡造成 7 点伤害，伤害来源为该玩家

### 焊接头盔 ×2

- 类型：装备
- 装备栏：1 格

**技能：焊接头盔**

- 技能描述：被动：受到的伤害减一。
- 技能类型：装备
- 触发时机：受到伤害时
- 强制发动：是
- 效果：本次受到的伤害值减 1

### 检查武器 ×3

- 类型：行动

**技能：检查武器**

- 技能描述：行动：所有玩家造成的伤害增加1，直到其回合结束。
- 技能类型：行动
- 可用阶段：行动阶段
- 可用条件：处于行动阶段，且玩家剩余行动次数大于 0
- 效果：场上所有玩家各获得 1 层「检查武器」标记（可叠加），持续至其各自回合结束；造成伤害时额外加层数点伤害

**子技能：检查武器_伤害**

- 触发时机：造成伤害时
- 强制发动：是
- 效果：本次伤害值额外加 X 点，其中 X 为该玩家的「检查武器」标记数

**子技能：检查武器_清除**

- 触发时机：回合结束前
- 强制发动：是
- 效果：移除该玩家的「检查武器」标记与相关子技能

### 启动汽车 ×2

- 类型：行动

**技能：启动汽车**

- 技能描述：行动：将任一玩家移动到任一已展示的地图块。
- 技能类型：行动
- 可用阶段：行动阶段
- 可用条件：处于行动阶段，且玩家剩余行动次数大于 0
- 目标选择：复合目标（1 名任意玩家 + 1 个已展示的地图块）
- 目标范围：均无距离限制
- 效果：将所选玩家移动到所选已展示地图块

### 升级 ×3

- 类型：行动
- 射程：中距离

**技能：升级**

- 技能描述：行动：放置在射程内的任一武器上，那张武器额外造成1点伤害。
- 技能类型：行动
- 可用阶段：行动阶段
- 可用条件：处于行动阶段，且玩家剩余行动次数大于 0
- 目标选择：1 个
- 目标筛选：`weapon == true` 的装备（武器）
- 目标范围：中距离（射程内任一玩家装备区）
- 效果：给目标武器添加「升级」标记；该武器造成伤害时额外造成 1 点伤害（子技能挂在武器持有者身上）

**子技能：升级_伤害**

- 触发时机：造成伤害时
- 强制发动：是
- 可用条件：造成伤害的卡牌拥有「升级」标记
- 效果：本次伤害值额外加 X 点，其中 X 为该武器的「升级」标记数

### 阅读使用说明 ×3

- 类型：行动
- 射程：中距离

**技能：阅读使用说明**

- 技能描述：行动：将射程内的一张装备牌装备给一名玩家（不可装回原持有者），然后你抓取一张牌。
- 技能类型：行动
- 可用阶段：行动阶段
- 可用条件：处于行动阶段，且玩家剩余行动次数大于 0
- 目标选择：复合目标（1 张中距离内玩家装备区的装备牌 + 1 名中距离内玩家）
- 目标范围：装备与接收者均为中距离；接收者可以是自己，但不能是该装备当前持有者
- 效果：将所选装备牌从原持有者处卸下并装备给目标玩家，然后抓取 1 张牌

- 类型：装备

- 技能描述：被动：每次你受到伤害时，自动炮塔对伤害来源造成4点伤害。
