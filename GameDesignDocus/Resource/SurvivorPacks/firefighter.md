# 消防员

## 角色详情

- 英文名：firefighter
- 生命值上限：32
- 初始生命值：32
- 潜行值：6
- 饥饿状态潜行值：5
- 装备栏容量：4
- 手牌上限：10

## 固有技能

### 拳打

- 技能描述：行动：对一个目标造成2点伤害。
- 射程：短距离
- 可用阶段：行动阶段
- 可用条件：处于行动阶段，且玩家剩余行动次数大于 0
- 目标筛选：任意目标（含玩家、怪物）
- 目标范围：短距离
- 效果：消耗 1 点行动次数，对目标造成 2 点伤害，伤害来源为该玩家

## 角色游戏牌堆

### 防火头盔 ×2

- 类型：装备
- 装备栏：1 格

**技能：防火头盔**

- 技能描述：被动：受到的伤害减一。
- 技能类型：装备
- 触发时机：受到伤害时
- 强制发动：是
- 效果：本次受到的伤害值减 1

### 打火机 ×3

- 类型：装备
- 装备栏：1 格
- 填充物：燃料 上限 2 初始 2
- 射程：短距离

**技能：打火机**

- 技能描述：行动：对射程内的所有怪物造成3点伤害。
- 技能类型：装备
- 可用阶段：行动阶段
- 可用条件：处于行动阶段，且玩家剩余行动次数大于 0，且打火机燃料数大于 0
- 目标选择：射程内所有目标
- 目标筛选：怪物类型的目标
- 目标范围：短距离
- 效果：消耗 1 点行动次数与 1 点打火机燃料，对所有目标造成 3 点伤害，伤害来源为该玩家

### 急救包 ×3

- 类型：行动
- 射程：短距离

**技能：急救包**

- 技能描述：行动：使射程内任一玩家一个目标恢复4点生命值。
- 技能类型：行动
- 可用阶段：行动阶段
- 可用条件：处于行动阶段，且玩家剩余行动次数大于 0
- 目标选择：1 个
- 目标筛选：人类类型的目标（含玩家幸存者，可自救或救他人）
- 目标范围：短距离
- 效果：使目标恢复 4 点生命值

### 猎枪 ×1

- 类型：装备
- 装备栏：1 格
- 填充物：弹药 上限 4 初始 4
- 射程：中距离

**技能：猎枪**

- 技能描述：行动：对射程内的一个目标造成4点伤害，然后对你面前的所有目标造成2点伤害。
- 技能类型：装备
- 可用阶段：行动阶段
- 可用条件：处于行动阶段，且玩家剩余行动次数大于 0，且猎枪弹药数大于 0
- 目标选择：1 个
- 目标筛选：任意目标
- 目标范围：中距离
- 效果：消耗 1 点行动次数与 1 点猎枪弹药，对主目标造成 4 点伤害，并对玩家所在地块的所有其他目标造成 2 点伤害，伤害来源为该玩家

### 灭火器 ×3

- 类型：行动

**技能：灭火器**

- 技能描述：行动：击晕射程内的所有怪物，直到你的下个回合开始。
- 技能类型：行动
- 可用阶段：行动阶段
- 可用条件：处于行动阶段，且玩家剩余行动次数大于 0
- 目标选择：射程内所有目标
- 目标筛选：怪物类型的目标
- 目标范围：短距离
- 效果：击晕射程内的所有怪物，持续至该玩家的下个回合开始时

### 能量饮料 ×2

- 类型：行动

**技能：能量饮料**

- 技能描述：行动：直到你的下个回合开始，你免疫饥饿伤害。你抓一张牌
- 技能类型：行动
- 可用阶段：行动阶段
- 可用条件：处于行动阶段，且玩家剩余行动次数大于 0
- 目标筛选：玩家自身
- 效果：玩家获得临时技能「能量饮料_饱腹」，持续至下个回合开始时；抓取 1 张牌

**子技能：能量饮料_饱腹**

- 触发时机：求生者饥饿状态结算前
- 强制发动：是
- 效果：取消本次饥饿状态结算

### 梯子 ×2

- 类型：装备
- 装备栏：1 格

**技能：梯子**

- 技能描述：被动：自动通过河流地图块的检定。弃置：抓取怪物卡前，可以弃置此装备，然后跳过抓取怪物卡的步骤。
- 技能类型：装备
- 触发时机：潜行检定前、抓取怪物卡前
- 效果：当触发「潜行检定前」且触发来源为河流地块时，跳过投骰并视为自动通过；当触发「抓取怪物卡前」时，玩家可选择弃置此装备以跳过本次抓怪

### 闪光棒 ×4

- 类型：行动

**技能：闪光棒**

- 技能描述：行动：将射程内的所有怪物纠缠的目标改成你。
- 技能类型：行动
- 可用阶段：行动阶段
- 可用条件：处于行动阶段，且玩家剩余行动次数大于 0
- 目标选择：射程内所有目标
- 目标筛选：怪物类型的目标
- 目标范围：长距离
- 效果：将射程内所有怪物的纠缠对象改为该玩家

### 我的斧子去哪儿了？ ×2

- 类型：行动

**技能：我的斧子去哪儿了？**

- 技能描述：行动：将游戏牌堆中的【值得信赖的斧子】置入你的装备区。并随机抓取一张拾荒卡。。
- 技能类型：行动
- 可用阶段：行动阶段
- 可用条件：处于行动阶段，且玩家剩余行动次数大于 0
- 效果：将玩家游戏牌堆中的「值得信赖的斧子」置入装备区（若牌堆中无此牌则记录日志）；玩家随机从场上拾荒牌堆颜中抓取 1 张拾荒牌

### 消防员的耐力 ×2

- 类型：行动

**技能：消防员的耐力**

- 技能描述：行动：移动最多三格，然后抓取一张牌。
- 技能类型：行动
- 可用阶段：行动阶段
- 可用条件：处于行动阶段，且玩家剩余行动次数大于 0
- 延迟消耗行动次数：是
- 效果：最多移动 3 格（每步选择相邻地块，可中途停止；移动失败则中止后续移动），首次移动时消耗 1 点行动次数；移动结束后抓取 1 张牌

### 野地夹克 ×2

- 类型：装备
- 装备栏：1 格

**技能：野地夹克**

- 技能类型：装备
- 可用阶段：行动阶段
- 可用次数：不限
- 可用条件：处于行动阶段，且玩家饥饿值小于 6
- 效果：玩家饥饿值增加 1 点，行动次数增加 1 点
