# 外星人类怪包

## 构成

- 外星收割者（首领）×1
- 外星指挥官（首领）×1
- 外星科学家（精英）×5
- 外星机械（精英）×4
- 外星入侵者（精英）×7
- 外星飞船（精英）×3
- 外星士兵（精英）×6

## 怪物详情

> 怪物卡进入求生者怪物区时会实体化，实体化后的怪物卡具备以下属性：怪物级别、怪物类型、最大生命值、当前生命值、攻击伤害、射程、技能。
> 本包怪物类型统一为"外星人"；部分技能在"造成伤害时"触发，需以伤害来源是否为外星人怪物作为判定条件。
> "烧毁"统一按"销毁（移出游戏）"处理，被销毁的牌不进入任何弃牌堆；销毁范围为目标玩家的手牌区与装备区。

### 外星收割者 ×1

- 英文名：alien_reaper
- 怪物类型：外星人
- 级别：首领
- 生命值上限：25
- 初始生命值：25
- 攻击伤害：5
- 射程：无（仅攻击其所纠缠的玩家）

**技能：外星收割者-摧毁装备**

- 技能描述：当此怪物卡被玩家抓取后，摧毁场上所有的装备牌。
- 技能类型：怪物
- 触发时机：怪物卡进入求生者怪物区后
- 强制发动：是
- 可用条件：无特殊条件
- 效果：场上所有玩家的装备区内所有装备牌被销毁（移出游戏）

**技能：外星收割者-烧毁**

- 技能描述：当此怪物卡攻击时，随机销毁目标玩家区域内的一张牌。
- 技能类型：怪物
- 触发时机：怪物攻击时
- 强制发动：是
- 可用条件：无特殊条件
- 效果：对所有受到攻击的目标玩家，从其手牌区与装备区中随机销毁一张牌（移出游戏）

- 英文名：alien_commander

- 生命值上限：22

**技能：外星指挥官-集结修复**

- 技能类型：怪物
- 触发时机：怪物卡进入求生者怪物区后
- 强制发动：是
- 可用条件：无特殊条件
- 效果：场上所有外星人类怪物（含本怪物自身）生命值回复至上限

**技能：外星指挥官-烧毁**

- 技能描述：当此怪物卡攻击时，随机销毁目标玩家区域内的两张牌。
- 技能类型：怪物
- 触发时机：怪物攻击时
- 强制发动：是
- 可用条件：无特殊条件
- 效果：对所有受到攻击的目标玩家，从其手牌区与装备区中随机销毁两张牌（移出游戏）

### 外星科学家 ×5

- 英文名：alien_scientist
- 怪物类型：外星人
- 级别：精英
- 生命值上限：9
- 初始生命值：9
- 攻击伤害：1
- 射程：无（仅攻击其所纠缠的玩家）

**技能：外星科学家-勒索装备**

- 技能描述：当此怪物卡被玩家抓取时，抓取该卡的玩家弃掉一张装备区内的装备，否则受到六点伤害。
- 技能类型：怪物
- 触发时机：怪物卡进入求生者怪物区后
- 强制发动：是
- 可用条件：无特殊条件
- 效果：抓取此卡的玩家若装备区有装备，则选择弃置一张装备或受到6点伤害；若装备区无装备，则直接受到6点伤害

**技能：外星科学家-协同强化**

- 技能描述：所有外星人类怪物攻击时，造成的伤害加一。
- 技能类型：怪物
- 触发时机：造成伤害时
- 强制发动：是
- 可用条件：伤害来源为外星人类怪物
- 效果：造成的伤害+1
