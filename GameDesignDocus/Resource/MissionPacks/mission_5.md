# 任务卡5

## 任务名

5. 拆除炸弹

## 任务难度

正常

## 启动面包车所需燃料

3

## 任务介绍

有传闻说，一枚锁在电厂里的炸弹即将爆炸，这将使整个反应堆燃烧。很明显，它被锁在一处只有高级人员才能出入的地方。一名老员工写的满是灰尘的日记本应该能帮我们进去。

目标：找到满是灰尘的日记本然后前往电厂。花费 2 个行动来解除炸弹。在解除炸弹后，你们只有 3 个回合来返回面包车上。

## 任务目标

1. 找到"满是灰尘的日记本"。
2. 解除"电厂"上的炸弹。
3. 给"面包车"添加"燃料"(0/3)。
4. 回合结束时，所有存活玩家在地图块"面包车"上，且"面包车"上没有任何怪物，就获得胜利。

## 任务特殊设置

- 将怪物牌堆中的首领级怪物牌随机分布到怪物牌堆中的下半部分。
- 有玩家进入带有"任务标记"的地块时，移除该地块上的"任务标记"，该玩家获得"满是灰尘的日记本"并抓取一张首领牌。
- 地图块"电厂"添加主动技能"解除炸弹"。 
"解除炸弹":{
    技能描述:"消耗2点行动，解除炸弹"
    可用条件:玩家手牌区有"满是灰尘的日记本"
    技能效果:开始3回合的游戏回合倒计时。
} 
- 游戏倒计时结束时，消灭所有不在地图块"面包车"上的玩家。
