# 任务卡4

## 任务名

4. 核冬天

## 任务难度

正常

## 启动面包车所需燃料

无

## 任务介绍

炸弹毫无预兆地爆炸了。所有大城市顷刻间化为灰尘。冬季马上就要到来，如果我们不储存足够的食物并找到一处安全地点的话，我们就没法过冬。

目标：收集 3 个燃料、2 个脏毯子和2 张老报纸，且食物类拾荒卡数量不小于5。带这些物品返回到避难所并摧毁所有尾随求生者的怪物。当所有玩家都在避难所里且所有怪物被摧毁，你们获得胜利。

## 任务完成条件

1. 收集物资:
    - 收集燃料(0/3)
    - 收集脏毯子(0/2)
    - 收集老报纸(0/2)
2. 回合结束时，所有存活玩家都在"避难所"且"避难所"上没有任何怪物，就获得胜利。

## 任务特殊设置

- 将怪物牌堆中的首领级怪物牌随机分布到怪物牌堆中的下半部分。
- 地图块"避难所"添加主动技能"提交物资"。 
"提交物资":{
    技能描述:"消耗1点行动，将手牌区、装备区中的\"燃料\"、\"脏毯子\"、\"老报纸\"提交任务。"
    可用条件:玩家装备区有"燃料"，或手牌区有"脏毯子"、"老报纸"
    技能效果:弃置玩家区域中的"燃料"、"脏毯子"、"老报纸"，然后更新任务进度。
}
