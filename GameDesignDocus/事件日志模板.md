# 事件日志模板

> 本文档列举游戏运行时事件日志的样例输出格式。
> 日志由 `LogColors` 工具类为各实体名着色（玩家蓝、怪物红、卡牌紫、技能黄、地块绿），通过 `EventBus.log_message` 信号推送至 UI 层。
> 日志触发时机与事件流程详见 `GameInstructions/04_事件流与变体.md`；信号清单详见 `GameSystem/System/EventBus.md`；着色规则详见 `GameSystem/System/LogColors.md`；实体 trigger 流程详见 `GameSystem/Core/Entity.md`。

## 二、单行为样例

- 玩家操控 "消防员" 使用 "值得信赖的斧子" 攻击 "僵尸士兵"时的游戏日志如下：
```
  "消防员" 消耗了 1 点行动点数
  "消防员" 对 "僵尸士兵" 使用了 "值得信赖的斧子"
  "僵尸士兵" 受到 "消防员" 造成的 4 点伤害
```
- 玩家操控 "消防员" 使用 "手枪" 攻击 "僵尸步行者"时的游戏日志如下:
```
  "消防员" 消耗了 1 点行动点数
  "消防员" 对 "僵尸步行者" 使用了 "手枪"
  "消防员" 对 "手枪" 消耗了 1 发填充物
  "僵尸步行者" 受到 "消防员" 造成的 2 点伤害
```
- 玩家操控的 "消防员" 被怪物 "僵尸士兵" 攻击时的日志如下：
```
  "僵尸士兵" 攻击了 "消防员"
  "消防员" 受到 "僵尸士兵" 造成的 4 点伤害
```
- 玩家操控 "消防员" 使用 "急救包" 时的游戏日志如下：
```
  "消防员" 消耗了 1 点行动点数
  "消防员" 使用了 "急救包"
  "消防员" 回复了 4 点生命值
```
- 玩家操控 "消防员" 使用 "弹药（少量）" 给 "手枪" 填充弹药时的日志如下：
```
  "消防员" 消耗了 1 点行动点数
  "消防员" 对 "手枪" 使用了 "弹药（少量）"
  "消防员" 对 "手枪" 填装了 2 发填充物
```
- 玩家操控 "消防员" 装备手牌区中 "野地夹克" 时的日志如下：
```
  "消防员" 消耗了 1 点行动点数
  "消防员" 使用了 "野地夹克"
  "消防员" 装备了 "野地夹克"
```
- 玩家操控 "消防员" 使用装备区中 "野地夹克" 技能时的日志如下：
```
  "消防员" 使用了 "野地夹克"
  "消防员" 增加了 1 点饥饿值
  "消防员" 增加了 1 点行动点数
```
 - 玩家操控 "消防员" 移动至未展示地图块时的日志如下：
```
  "消防员" 消耗了 1 点行动点数
  "消防员" 从 "购物中心" 移动至 "河流"
  "消防员" 展示了 "河流"
```
- 玩家操控 "消防员" 移动至 "医院" 时的日志如下：
```
  "消防员" 消耗了 1 点行动点数
  "消防员" 从 "河流" 移动至 "医院"
  "消防员" 触发了 "医院"
  "消防员" 回复了 1 点生命值
```
