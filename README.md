# 末日启示录 PC 版

> 基于实体桌游《Maximum Apocalypse》的 PC 单机重制版，使用 Godot 4.7 + GDScript 开发。

## 项目简介

《末日启示录 PC 版》是一款 1–6 人合作类后启示录求生游戏，将原版桌游《Maximum Apocalypse》的核心体验移植到 PC 平台。

文明已经崩溃，玩家扮演在僵尸、突变体、机器人、外星人四类末日威胁中挣扎求生的幸存者，需要探索随机生成的地图、收集物资、击杀怪物，最终完成指定任务目标并逃离废土。

## 玩法概述

- **合作求生**：1–6 名玩家共同完成任务；全员死亡即失败。可选「同生共死」变体：任一玩家死亡即全员失败
- **卡牌驱动**：每名幸存者拥有专属牌堆，武器、道具、技能均以卡牌形式呈现
- **回合制流程**：每回合依次经历「怪物出生 → 抓牌 → 行动 → 回合结束结算」，每回合通常 4 个行动点
- **程序化地图**：任务卡决定地块布局，地块随机填充
- **四类末日威胁**：僵尸、突变体、机器人、外星人，各自拥有独立的怪物牌堆与行为模式
- **拾荒系统**：红 / 绿 / 蓝三色拾荒牌堆按地块颜色抽取
- **饥饿机制**：忽略进食会逐步加重饥饿，最终造成不可减免的伤害
- **13 个任务**：任务 0–12，胜利条件、地图、首领与特殊规则各不相同；玩家模式按通关进度解锁，全通后解锁随机任务与变体

## 当前状态

玩家模式可选用 5 名求生者：消防员、枪手、猎人、机械师、外科医生。老兵第一版过复杂，正在重新设计，玩家模式锁定。

已实现内容包括：

- 13 个任务（声明式任务组件：胜利 / 失败 / 触发 / 行动）
- 成就与跨对局档案、任务解锁
- 游戏内 Wiki、任务 0 聚光灯教程
- 统一事件调度、实体标记

设计文档见 [GameDesignDocus/README.md](GameDesignDocus/README.md)。后续将持续迭代。
