# 任务目标

> 每个任务都为求生者设定了不同的剧本和目标。
> 大多数任务要求完成目标并带着一定数量的燃料返回面包车逃离；部分任务（4/8/9/11）不通过启动面包车胜利，胜利条件完全由任务目标定义。
> 任务数据定义见 [Resource/MissionPacks/](../Resource/MissionPacks/)，任务配置结构见 [GameSystem/Game/Game.md](../GameSystem/Game/Game.md#任务配置结构missionconfig)。

---

## 任务字段结构

每个任务包（`basic-mission_0.md` ~ `basic-mission_12.md`）按以下结构定义，详见 [Resource/README.md 任务包格式](../Resource/README.md#任务包missionpacks)：

| 字段 | 类型 | 说明 |
|------|------|------|
| 任务名 | 字符串 | 任务编号 + 名称（如 "5. 拆除炸弹"） |
| 任务难度 | 枚举 | 特别简单 / 非常简单 / 简单 / 正常 / 困难 / 非常困难 |
| 启动面包车所需燃料 | 数值 或 NULL | 数值表示需往面包车添加燃料；NULL 表示不通过面包车胜利 |
| 任务介绍 | 文本 | 剧情背景 |
| 任务目标 | 文本 | 玩家可读的目标说明 |
| 任务特殊设置 | 文本 | 初始状态、首领卡放置、目标标记布置等 |
| 任务怪物包类型 | 引用 | `zombie` / `mutant` / `alien` / `robot`，对应 [MonsterPacks/](../Resource/MonsterPacks/) |
| 任务地图块配置 | 列表 | 地块池（按数量展开，供 `1`/`3` 位置随机抽取） |
| 任务地图要求 | 二维数组 + 标记定义 | 默认地图 + 特殊位置地块名 + 目标标记定义 |
| 任务拾荒牌堆配置 | 三色牌堆 | 红 / 绿 / 蓝三色拾荒牌堆的牌组成 |

### MissionConfig 运行时结构

游戏初始化时，任务包字段被加载到 `game.任务配置`（MissionConfig 结构），详见 [GameSystem/Game/Game.md](../GameSystem/Game/Game.md#任务配置结构missionconfig)：

| 字段 | 类型 | 说明 |
|------|------|------|
| 启动面包车所需燃料 | Int / NULL | NULL 时 `checkWinCondition()` 跳过面包车相关检查 |
| 检查胜利条件 | `() => Boolean` | 任务包提供的胜利判定函数，由 `game.检查任务胜利条件()` 委托调用 |
| 任务状态 | `Dict<String, Any>` | 任务运行时状态（如「已记录科学家信息」、「科学家装备牌」等），各任务自行约定键名 |

## 胜利条件

胜利条件在玩家回合结束时检查（[GameStateMachine.checkWinCondition()](../GameSystem/Core/GameStateMachine.md#checkwincondition)），玩家依然会在回合结束前受到伤害。

### 普通胜利（燃料值非 NULL）

任务 0/1/2/3/5/6/7/10/12 适用。需**同时**满足以下条件：

1. **任务目标完成**：`game.检查任务胜利条件()` 返回 true（由任务包提供的 `检查胜利条件` 函数判断）
2. **面包车燃料充足**：所有玩家投入到面包车的燃料总和 ≥ `任务配置.启动面包车所需燃料`
3. **所有存活玩家返回**：所有存活玩家位于"游戏结束点"地块（多数任务为面包车，部分任务为军事基地等）
4. **结束点无怪物**：游戏结束点地块上没有任何怪物和怪物标记

### 特殊胜利（燃料值为 NULL）

任务 4/8/9/11 适用。`任务配置.启动面包车所需燃料 == NULL`，`checkWinCondition()` 跳过条件 2/3/4，**仅依赖条件 1**（`game.检查任务胜利条件()` 返回 true）。胜利条件完全由任务目标定义，例如：

- **任务 4 核冬天**：收集物资返回避难所并摧毁所有尾随怪物
- **任务 8 情报恢复**：带着科学家信息返回军事基地
- **任务 9 人类反击**：摧毁 2 个外星发射器并把科学家带到坠毁点上传病毒
- **任务 11 保护基地**：清除 3 个目标标记后返回军事基地并杀死所有玩家面前的怪物卡

详见 [G_gameOver.md 游戏胜利](G_gameOver.md)。

## 失败条件

失败条件**即时触发**（不需等到回合结束），详见 [G_gameOver.md 游戏失败](G_gameOver.md)：

1. **所有玩家死亡**：所有求生者被消灭
2. **同生共死模式**：开启 `game.同生共死模式` 时，任一玩家死亡即所有求生者输掉游戏（在 `playerDeath` 末尾全灭判定之前检查，详见 [L_gameVariants.md](L_gameVariants.md)）
3. **怪物牌堆耗尽**：怪物牌堆重洗后仍为空（所有怪物卡都在场上）
4. **任务特定失败**：如任务 8，潜行检定失败且玩家没有日记本时立即 `game.gameOver("lose")`

## 任务特殊设置元素

### 首领卡机制

部分任务在初始设置中将首领卡洗入怪物牌堆：

| 任务 | 首领卡设置 |
|------|----------|
| 1 | 把科学家和首领卡放到一边，到达警察局的第一名玩家抓取首领卡 |
| 3 | 从怪物牌堆抓 9 张 + 首领卡洗混，放到牌堆底 |
| 4 | 从怪物牌堆抓 9 张 + 首领卡洗混，放到牌堆底 |
| 5 | 通过目标标记效果触发：到达时 `player.drawBossCard()` |
| 6 | 从怪物牌堆抓 5 张 + 首领卡洗混，放到牌堆底 |
| 7 | 通过目标标记效果触发：展示地块时 `player.drawBossCard()` |
| 8 | 第一个到达目标标记所在地块的玩家抓取首领卡 |
| 9 | 把 2 张首领卡洗入怪物牌堆 |
| 11 | 把首领卡洗入怪物牌堆下半部 |
| 12 | 把首领卡随机洗入怪物牌堆 + 在牌堆底额外放一张 |

**实现**：`player.drawBossCard()` 从怪物牌堆中筛选 `怪物级别 == "首领"` 的卡，放到牌堆顶部后复用 `drawMonster(1)` 完整流程，详见 [Player.md §十四](../GameSystem/Entities/Player.md#十四任务系统方法)。

### 目标标记机制

任务 5/7/8/9/10/11/12 使用目标标记。目标标记挂载到地块上，玩家进入地块时触发标记效果（一次性）。详见 [MapBlock.md 目标标记结构](../GameSystem/Entities/MapBlock.md#目标标记结构objectivemark)。

| 任务 | 标记数 | 标记效果 |
|------|-------|---------|
| 5 | 1 | 获得满是灰尘的日记本 + 抓首领卡 |
| 7 | 1 | 展示地块的玩家抓首领卡 |
| 8 | 1 | 投潜行检定：成功可解救科学家；失败时若有日记本则记录信息，否则游戏失败 |
| 9 | 2 | 被守卫的外星发射器：预置 2 个怪物标记，需用炸药摧毁 |
| 10 | 3 | 标记 1：收集多余零件+医疗用品；标记 2：抓首领卡+收集脏毯子；标记 3：收集燃料+医疗用品 |
| 11 | 3 | 机器人攻击部队：预置 3 个怪物标记，清除所有怪物标记后移除目标标记 |
| 12 | 3 | 任务目标：需用大炸药摧毁标记地块 |

**特殊字段**：
- `初始怪物标记数`：标记地块预置的怪物标记数（任务 9 每个 2 个、任务 11 每个 3 个）
- `移除条件`：声明后 `removeMonsterMark` 时自动检查，满足条件则自动移除目标标记（典型场景：任务 11「清除所有怪物标记后移除」）

### 科学家机制

任务 1/3/8/9 涉及科学家：

| 任务 | 科学家角色 |
|------|----------|
| 1 | 解救警察局的科学家，带回面包车 |
| 3 | 科学家作为装备牌一直装备在玩家面前，同地块玩家可交易，需带到医院 |
| 8 | 潜行检定成功可解救科学家；失败时若有日记本则记录科学家信息 |
| 9 | 把科学家带到坠毁点上传病毒 |

**实现**：
- `player.获得解救科学家的选项()` — 让玩家选择是否花费 1 行动解救科学家，装备到面前（科学家预存储在 `任务状态["科学家装备牌"]`）
- `player.记录科学家信息()` — 在 `game.任务配置.任务状态` 中标记 `"已记录科学家信息" = true`

详见 [Player.md §十四](../GameSystem/Entities/Player.md#十四任务系统方法)。

## 13 个任务概览

| # | 任务名 | 难度 | 燃料 | 怪物包 | 胜利条件分类 | 任务核心目标 |
|---|------|------|------|--------|------------|------------|
| 0 | 教程 | 特别简单 | 4 | zombie | 普通胜利 | 找 4 桶燃料逃到面包车（教学关，出生点为购物中心） |
| 1 | 解救科学家 | 简单 | 4 | zombie | 普通胜利 | 在警察局花 2 行动解救科学家，带回面包车 |
| 2 | 收集样本 | 非常简单 | 4 | zombie | 普通胜利 | 杀 8 个特定僵尸（步行者/喷吐者/狗/士兵各 2）收集样本 |
| 3 | 研制解药 | 简单 | 4 | zombie | 普通胜利 | 收集 2 医疗用品 + 3 解毒剂，带科学家到医院研制解药 |
| 4 | 核冬天 | 正常 | NULL | mutant | 特殊胜利 | 收集 3 燃料 + 2 脏毯子 + 2 老报纸 + 食物≥5，返回避难所并摧毁所有尾随怪物 |
| 5 | 拆除炸弹 | 正常 | 3 | mutant | 普通胜利 | 找满是灰尘的日记本→前往电厂花 2 行动解除炸弹→3 回合内返回面包车 |
| 6 | 核辐射 | 正常 | 3 | mutant | 普通胜利 | 收集 3 多余配件修面包车（修 3 次）；怪物出生投 7 时展示/移除最外围地块 |
| 7 | 侦查外星人地区 | 困难 | 4 | alien | 普通胜利 | 展示所有地图块后带燃料返回面包车 |
| 8 | 情报恢复 | 困难 | NULL | alien | 特殊胜利 | 到目标标记地块投潜行检定，成功解救科学家或失败时用日记本记录信息，返回军事基地 |
| 9 | 人类反击 | 非常困难 | NULL | alien | 特殊胜利 | 用炸药摧毁 2 个外星发射器（先清除预置怪物标记），把科学家带到坠毁点上传病毒 |
| 10 | 运输 | 困难 | 6 | robot | 普通胜利 | 收集 6 燃料 + 3 脏毯子 + 2 医疗用品 + 2 多余零件，返回军事基地（出生点为面包车，3 个目标标记给物资） |
| 11 | 保护基地 | 困难 | NULL | robot | 特殊胜利 | 清除 3 个目标标记（每个预置 3 怪物标记，全清后移除），返回军事基地并杀死所有玩家面前的怪物卡 |
| 12 | 烧死那群机器人 | 非常困难 | 3 | robot | 普通胜利 | 用大炸药摧毁 3 个标记地块，带燃料返回面包车 |

> **难度递进**：教程（0）→ 简单（1/2/3）→ 正常（4/5/6）→ 困难（7/8/10/11）→ 非常困难（9/12）
>
> **怪物包分布**：zombie（0-3）/ mutant（4-6）/ alien（7-9）/ robot（10-12），按难度递进引入新怪物类型。
>
> **胜利条件分布**：普通胜利 9 个（0/1/2/3/5/6/7/10/12，需面包车燃料）/ 特殊胜利 4 个（4/8/9/11，NULL 燃料）。

## 任务系统方法

任务系统方法定义在 [Player.md §十四 任务系统方法](../GameSystem/Entities/Player.md#十四任务系统方法)：

| 方法 | 说明 |
|------|------|
| `player.收集物品(卡牌名, 数量)` | 直接生成新卡加入手牌区（通过 `game.createScavengeCard()` 克隆），用于目标标记效果发放物资 |
| `player.hasItem(卡牌名)` | 搜索手牌区 + 装备区判断是否持有指定卡牌 |
| `player.drawBossCard()` | 从怪物牌堆筛选首领卡，放到牌堆顶部后复用 `drawMonster(1)` 完整流程 |
| `player.获得解救科学家的选项()` | 让玩家选择是否花费 1 行动解救科学家，装备到面前 |
| `player.记录科学家信息()` | 在 `game.任务配置.任务状态` 中标记 `"已记录科学家信息" = true` |

Game 类方法：

| 方法 | 说明 |
|------|------|
| `game.检查任务胜利条件()` | 委托给 `game.任务配置.检查胜利条件()` |
| `game.createScavengeCard(卡牌名)` | 工厂方法，从 ScavengePacks 定义克隆新卡 |
