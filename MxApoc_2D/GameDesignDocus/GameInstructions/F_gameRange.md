# 游戏射程

## 玩家射程

"无"：玩家只能指定自己作为目标。

"短距离": 玩家在‘1’位置，只能指定‘1’位置上的怪物和玩家作为目标。
Map = [
    [0, 0, 0],
    [0, 1, 0],
    [0, 0, 0]
]

"中距离": 玩家在‘1’位置，只能指定‘1’和’2‘位置上的怪物和玩家作为目标。
Map = [
    [0, 0, 0, 0, 0],
    [0, 0, 2, 0, 0],
    [0, 2, 1, 2, 0],
    [0, 0, 2, 0, 0],
    [0, 0, 0, 0, 0]
]

"长距离": 玩家在‘1’位置，只能指定‘2’和’3‘位置上的怪物和玩家作为目标。 # 注意：玩家不能指定‘1’位置上的怪物和玩家作为目标。
Map = [
    [0, 0, 3, 0, 0],
    [0, 3, 2, 3, 0],
    [3, 2, 1, 2, 3],
    [0, 3, 2, 3, 0],
    [0, 0, 3, 0, 0]
]

"Infinity"：玩家可以指定任意距离的怪物和玩家作为目标。

## 怪物射程

Map = [
    [0, 0, 3, 0, 0],
    [0, 3, 2, 3, 0],
    [3, 2, 1, 2, 3],
    [0, 3, 2, 3, 0],
    [0, 0, 3, 0, 0]
]

"无"：玩家面前的怪物只会攻击当前玩家 # 怪物只会攻击其所纠缠的玩家，不会攻击其他玩家

"短距离": 玩家在‘1’位置，玩家面前的怪物会攻击‘1’位置上的所有玩家

"中距离": 玩家在‘1’位置，玩家面前的怪物会攻击‘1’和’2‘位置上的所有玩家

"长距离": 玩家在‘1’位置，玩家面前的怪物会攻击’1‘、‘2’和’3‘位置上的所有玩家

"Infinity": 玩家面前的怪物会攻击场上所有玩家。
