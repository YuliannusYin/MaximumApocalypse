# 开始游戏

1. 玩家点击"开始游戏"按钮，进入游戏房间界面，房主为创建游戏房间的玩家。
游戏房间界面: 
    游戏设置（左边）：
        · 房主选择要进行的任务，或者选择“随机任务”。
        · 房主可以进行一些额外设置，比如：是否开启变体等等。
    任务详情（中间）：
        · 在房主选择的任务后，这个区域会加载这次任务的详情，比如：任务名、任务难度、任务介绍等等。
        · 任务详情请参考：[任务详情](../Resource/MissionPacks/basic-mission_1.md)
        · 最下面是"开始游戏"按钮，点击后开始加载进入游戏。
    玩家设置（右边）：
        · 房主可以选择要进行的任务，或者选择“随机任务”。
        · 房主可以添加或删除游戏座位，最少1个座位，最多4个座位。 # 每个座位对应游戏中要扮演的一个求生者。
        · 房主可以邀请玩家进入游戏房间，比如：player1 = 房主、player2 = 求生者233。
        · 房主可以设置游戏座位上的玩家，比如：seat1 = player1、seat2 = player2。 # 也可以往座位上添加ai玩家，比如：seat1 = player1，seat2 = ai，seat3 = ai。
        · 在座位上的玩家可以选择自己要扮演的求生者，比如：seat1选择扮演”消防员“，seat2选择扮演”枪手“。
        · 所有玩家的座位都要设置好，才能开始游戏。
2. 设置完游戏房间后，点击游戏房间界面里的的"开始游戏"按钮，开始加载进入游戏。

# 游戏初始化

1. 加载本局游戏的所有求生者角色卡、立像和求生者者游戏牌堆。
2. 根据任务加载本局游戏的所有怪物卡，并把它们洗混组成怪物牌堆。
3. 根据任务说明构建三个不同的拾荒牌堆（蓝、绿、红）。分别洗乱这些牌堆。
4. 根据任务说明构建地图。
5. 根据任务说明, 将玩家立像放到游戏地图中的初始地图块上。
6. 初始化游戏区域：
    全局区域：
        A. 怪物牌堆 # 如果怪物牌堆空了，就把怪物弃牌堆重新洗成新的牌堆。
        B. 怪物弃牌堆
        C. 三色拾荒牌堆 # 如果拾荒牌堆空了，不会重洗拾荒弃牌堆。
        D. 拾荒弃牌堆 # 不分颜色（所有颜色的拾荒牌弃置后都进入此弃牌堆）
        E. 地图区域
        F. 卡牌结算区
        G. 所有玩家的区域
    单个玩家区域：
        A. 求生者角色卡 # 每个玩家都有一个求生者角色卡，用于表示玩家的状态，比如：饥饿值，生命值等。
        B. 求生者手牌区
        C. 求生者装备区
        D. 求生者怪物区 # 纠缠玩家的怪物卡所在区域，其中纠缠玩家的怪物也叫"玩家面前的怪物"。 # 纠缠玩家的怪物与玩家在同一个地图块内。
        E. 求生者游戏牌堆 # 如果游戏牌堆空了，不会重新洗游戏牌弃牌堆。
        F. 求生者游戏牌弃牌堆

# 游戏开局

1. 游戏初始化完成后，每个玩家从对应的求生者游戏牌堆中抓4张牌作为初始手牌。 # 每名玩家的手牌上限是10。
2. 此时每名玩家都可以选择是否进行一次重调，把最多4张刚抓的卡牌洗回牌堆，让后抓取等量的卡牌。
3. 每名玩家抓取一张怪物卡，放到自己的角色面前。 # 每个纠缠玩家的怪物卡会停留在玩家的角色面前（即使玩家移动了），直到被消灭或者通过其它卡牌的效果被赶走。 # 玩家可以攻击其它玩家面前的怪物，只要该怪物在该玩家的攻击范围内。
4. 完成这些后，正式开始游戏，按照游戏房间的座位次序，依次进行回合。

# 抓取怪物卡

玩家抓取怪物卡后，怪物卡会在进入玩家的求生者怪物区时进行实体化：
    每个怪物卡都具备以下属性：
        - 怪物纠缠对象 # 一个怪物卡在同一时刻只能纠缠一个玩家
        - 怪物类型
        - 怪物最大生命值
        - 怪物当前生命值
        - 怪物伤害值
        - 怪物射程
        - 怪物技能
