# 任务卡8

## 任务名

8. 情报恢复

## 任务难度

困难

## 启动面包车所需燃料

NULL（本任务不通过启动面包车胜利，胜利条件由任务目标定义：带着科学家信息返回军事基地）

## 任务介绍

我们的一名科学家成功黑入外星母舰并窃取了一些情报。但是我们最近与他失去了联系。我们需要你去调查一下他最近出现的地点，务必带着日记本，不管他说什么，都记下带回来。

## 任务目标

目标：到达目标标记所在地图块并带着信息返回军事基地。当到达目标标记所在地块时，投一次潜行检定。如果成功，科学家还活着，你们可以花费 1 个行动来解救他，把他装备到一名玩家面前。如果失败，且该玩家拥有日记本，你们记下来科学家弥留之际对你们说的信息。如果失败且该玩家没有日记本，你们输掉游戏。

## 任务特殊设置

设置：正面向上放置军事基地地图块。把 1 个目标标记放到离军事基地至少 5 个地图块距离的 1 个地图块上。把科学家拾荒卡放到一边。第一个到达目标标记所在地图块的玩家抓取首领卡。

## 目标标记定义

目标标记1 {
    标记ID: "标记1"
    标记描述: "情报恢复：到达时投潜行检定，成功可解救科学家，失败则需日记本否则游戏失败"
    标记效果: (player) => {
        # 投潜行检定（复用潜行检定流程，独立于地块怪物标记）
        success = player.sneakJudge()
        if (success) {
            game.log("潜行检定成功！科学家还活着。")
            # 玩家可花费 1 行动解救科学家，装备到面前（见 Player.获得解救科学家的选项）
            player.获得解救科学家的选项()
        } else {
            # 失败：检查是否拥有日记本
            if (player.hasItem("满是灰尘的日记本")) {
                game.log("潜行检定失败！科学家弥留之际说出了信息，记在日记本上。")
                # 记录科学家信息（任务胜利条件之一，见 Player.记录科学家信息）
                player.记录科学家信息()
            } else {
                # 无日记本：游戏失败
                game.log("潜行检定失败且没有日记本！游戏失败。")
                game.gameOver("lose")
            }
        }
    }
}
