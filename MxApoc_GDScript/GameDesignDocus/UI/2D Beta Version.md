# 2D Beta Version (2D测试版设计方案)

## 加载界面

灰屏界面，中间几个白色的小球在中间旋转，下面显示加载中...

## 游戏场景

根据游戏地图的大小生成一张灰色的桌子，桌子中间就是地图块构成的游戏地图。
玩家的摄像头的中点默认正对着桌子的中间。
玩家可以“长按鼠标右键”移动摄像头。
玩家的摄像头的中点不能移出桌子的范围。

## 玩家摄像头界面设计

游戏窗口大小：默认1430*780(宽*高)，支持全屏和拉伸。窗口的基点（0，0）在左上角。

### 中间

卡牌结算区{
    形状：矩形
    大小：600*400
    位置：（400，190）
}
> 平时情况下不显示，只有玩家“拖拽卡牌时”才会显示。
> 所有还在结算中的卡牌都会先显示在这个地方，结算完后才会消失进入弃牌堆。

手牌显示区{
    形状：矩形
    大小：890*150
    位置：（300，610）
}
> 玩家可以将“鼠标”悬停在单张牌上，查看卡牌的详细信息
> 玩家可以“单击鼠标左键”选中 '手牌显示区' 中的一张手牌。（卡牌边框高亮）
> 玩家可以对一张手牌“双击鼠标左键”使用这张卡牌。
> 玩家可以“按住鼠标左键”拖拽手牌区中的牌，点击“鼠标右键”取消拖拽。
> 若玩家将手牌拖拽进入 '手牌结算区' 并松开“鼠标左键”则等同于使用这张卡牌。
