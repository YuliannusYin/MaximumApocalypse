## 方法清单

| 方法签名 | 定义位置 | 简述 |
|---------|---------|------|
| `target.damage(num, source, type=NULL)` | [GameSystem/DamageFlow.md](GameSystem/DamageFlow.md) | 伤害结算流程，含 8 个事件钩子节点 |
| `target.playerDeath(source)` | [GameSystem/DeathFlow.md](GameSystem/DeathFlow.md) | 玩家死亡流程（清理怪物/游戏牌/拾荒卡 + 全灭判定） |

| `player.increaseHunger(num)` | [GameSystem/PlayerState.md](GameSystem/PlayerState.md) | 增加饥饿值（含翻面与饥饿伤害结算） |
| `player.decreaseHunger(num)` | [GameSystem/PlayerState.md](GameSystem/PlayerState.md) | 减少饥饿值（最低降至 1，清除饥饿伤害标记） |
| `player.poison()` | [GameSystem/PlayerState.md](GameSystem/PlayerState.md) | 中毒结算（无来源伤害） |
| `player.judge()` | [GameSystem/Judge.md](GameSystem/Judge.md) | 投两颗大骰子返回点数和 |
| `player.sneakJudge()` | [GameSystem/Judge.md](GameSystem/Judge.md) | 潜行检定 |
| `player.monsterSpawnJudge()` | [GameSystem/Judge.md](GameSystem/Judge.md) | 怪物出生检定 |
| `player.draw(n)` | [GameSystem/DrawFlow.md](GameSystem/DrawFlow.md) | 从玩家游戏牌堆抓 n 张牌到手牌区（含 4 个事件钩子节点，牌堆空时触发玩家死亡） |
| `player.drawScavenge(n, pile)` | [GameSystem/DrawFlow.md](GameSystem/DrawFlow.md) | 从指定拾荒牌堆抓 n 张牌到手牌区（含 4 个事件钩子节点，逐张抓取触发「时」，pile 参数为 pile 对象） |
| `player.drawMonster(n)` | [GameSystem/DrawFlow.md](GameSystem/DrawFlow.md) | 从怪物牌堆抓 n 张怪物卡到玩家怪物区（含 6 个事件钩子节点，逐张实体化，牌堆空时重洗弃牌堆） |
| `player.discard(target, position=NULL, quantity=1, type=NULL)` | [GameSystem/DiscardFlow.md](GameSystem/DiscardFlow.md) | 弃置卡牌到对应弃牌堆（重载：card/cards/name+position/type，含 3 个事件钩子节点，按 source 自动分派弃牌堆） |
| `player.removeCard(target, position=NULL, quantity=1)` | [GameSystem/DiscardFlow.md](GameSystem/DiscardFlow.md) | 销毁卡牌移出游戏（重载：card/cards/name+position，含 3 个事件钩子节点，不进入弃牌堆） |
