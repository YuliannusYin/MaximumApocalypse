# 游戏事件流程

## "source攻击target" 流程
1. source攻击target前
2. target受到伤害前
3. source攻击target时 # 触发”造成伤害时“事件
4. target受到伤害时 # 触发”受到伤害时“事件
5. source攻击target后
6. target受到伤害后

## "玩家从所在地块移动到目标地块" 流程
1. 离开所在地块前
2. 离开所在地块时
3. 进入目标地块前
4. 移动时 # 坐标变更
5. 离开所在地块后
6. 进入目标地块时
7. 进入目标地块后 # 展示地图块并触发展示效果
8. 潜行检定 # 如果目标地块上有怪物标记，玩家需要进行潜行检定

## "玩家抓取怪物" 流程
1. 抓取怪物卡前
2. 抓取怪物卡时
3. 怪物卡进入求生者怪物区前 # 怪物卡实体化
3. 怪物卡进入求生者怪物区时 
4. 怪物卡进入求生者怪物区后

## "怪物死亡流程" 流程
1. 怪物死亡前
2. 怪物死亡时 # 触发怪物死亡事件
3. 怪物死亡后 # 将怪物卡从求生者怪物区移除，进入怪物卡弃牌堆
