# 游戏事件流程

## "source攻击target" 流程
1. source攻击target前
2. target受到伤害前
3. source攻击target时
4. target受到伤害时
5. source攻击target后
6. target受到伤害后

## "玩家从所在地块移动到目标地块" 流程
1. 离开所在地块前
2. 离开所在地块时
3. 进入目标地块前
4. 移动时 # 坐标变更
5. 离开所在地块后
6. 进入目标地块时
7. 进入目标地块后 # 展示地图块并触发展示效果
8. 潜行检定 # 如果目标地块上有怪物标记，玩家需要进行潜行检定
