## "玩家从所在地块移动到目标地块" 流程
1. 离开所在地块前 # player.trigger("离开地块前")
2. 离开所在地块时 # player.trigger("离开地块时")，如森林：同回合内进入又离开→抓怪物
3. 离开所在地块后 # player.trigger("离开地块后")
4. 获取目标地块技能 # player.获取地块技能(target)，先获取再准入检定
5. 进入目标地块前 # player.trigger("进入地块前")，准入检定，如河流：潜行失败→event.cancel()，回滚 target.清除技能(player)
6. 移动时 # 坐标变更
7. 清理旧地块技能 # source.清除技能(player)，移动成功后才清理
8. 进入目标地块时 # player.trigger("进入地块时")，一次性进入效果
9. 进入目标地块后 # 展示地图块（触发"展示地块时"），player.trigger("进入地块后")
10. 潜行检定 # 如果目标地块上有怪物标记，玩家需要进行潜行检定

## "玩家抓取怪物" 流程
1. 抓取怪物卡前
2. 抓取怪物卡时
3. 怪物卡进入求生者怪物区前 # 怪物卡实体化
3. 怪物卡进入求生者怪物区时 
4. 怪物卡进入求生者怪物区后

## "怪物死亡流程" 流程
1. 怪物死亡前
2. 怪物死亡时 # 触发怪物死亡事件
3. 怪物死亡后 # 将怪物卡从求生者怪物区移除，进入怪物卡弃牌堆
