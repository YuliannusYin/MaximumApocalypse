# 游戏流程

## 每名玩家按座位顺序轮流进行回合直到游戏结束
游戏开局后->seat1玩家回合->seat2玩家回合->seat3玩家回合->seat4玩家回合->seat1玩家回合->seat2玩家回合->seat3玩家回合->seat4玩家回合->... ...->游戏结束

# 玩家回合流程（每个玩家每个回合的流程）

1. 进入玩家回合

2. 回合开始前
3. 回合开始时

4. 怪物出生前
5. 怪物出生时：
    进行一次怪物出生检定。 # 查看[怪物出生检定](../GameInstructions/E_gameJudge.md)。

6. 摸牌阶段前
6. 摸牌阶段：
    从求生者的游戏牌堆抓取一张牌 # 当求生者的游戏牌堆空了不能抓牌时，求生者被消灭。

7. 行动阶段前:
    如果玩家所在地块上有怪物标记，玩家需要进行潜行检定。 # 查看[潜行检定](../GameInstructions/E_gameJudge.md)。
8. 行动阶段：
    执行行动你可以按任意组合执行以下4个行动。你可以多次执行同一行动。你必须执行总共4个行动:
        横向或竖向移动1格
        从你的求生者游戏牌堆中抓1张牌
        从你的手牌中打出1张牌
        执行1张已经在游戏中的卡牌上的行动
        拾荒:根据你当前地点(如果可以的话)押1张拾荒卡
    免费行动:
        每回合一次作为一个免费行动，你可以弃掉两张求生者游戏牌来从你的求生者游戏牌堆中抓一张新牌。
        每回合一次作为一个免费行动，你可以和另一名与你在同一地图块上的玩家交易拾荒卡。

9. 行动阶段结束前
10. 行动阶段结束时

11. 求生者饥饿状态结算前
12. 求生者饥饿状态结算：
    player.increaseHunger(1) #求生者增加一点饥饿值，详情查看玩家技能中的[增加饥饿值方法](../PlayerSkill.md)

13. 求生者中毒状态结算前
14. 求生者中毒状态结算：
    如果玩家身上有中毒标记，则玩家受到等量中毒标记数量的伤害。

15. 面前怪物行动前
16. 面前怪物行动时：
    玩家面前的怪物会根据进入玩家的求生者怪物区的顺序进行行动，先进入的先行动。 # 查看[怪物行动](../GameInstructions/I_monsterAction.md)。

17. 回合结束前
18. 回合结束时

19. 退出玩家回合
